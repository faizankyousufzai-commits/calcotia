¿Qué es una ecuación de segundo grado?

Una ecuación de segundo grado, también llamada ecuación cuadrática, es una igualdad con una incógnita elevada al cuadrado, de forma general ax² + bx + c = 0, con a distinto de cero. Resolverla es encontrar los valores de x que hacen verdadera la igualdad. Esta calculadora de ecuaciones de segundo grado te da las soluciones paso a paso, con el discriminante y el vértice de la parábola.

La fórmula general y el discriminante

La fórmula general resuelve cualquier ecuación de segundo grado: x es igual a menos b más o menos la raíz cuadrada del discriminante, todo dividido entre 2a. El discriminante es D = b² − 4ac, y decide cuántas soluciones hay antes de calcular nada. Si es mayor que cero, hay dos soluciones reales distintas. Si es cero, hay una sola, la raíz doble. Si es menor que cero, no hay soluciones reales: las dos son complejas conjugadas.

El vértice, el punto más alto o más bajo de la parábola, está en x igual a menos b entre 2a, y su altura es c menos b al cuadrado entre 4a. Si a es positivo, el vértice es un mínimo; si es negativo, un máximo. En el vértice la pendiente de la parábola es cero; la calculadora de pendiente mide inclinaciones entre dos puntos.

Ecuaciones incompletas

Si falta el término en x, ax² + c = 0, se despeja x al cuadrado y se saca la raíz con sus dos signos: x² − 9 = 0 da x = 3 y x = −3.

Si falta el término independiente, ax² + bx = 0, se saca factor común x y queda x por (ax + b) = 0: una solución es siempre x = 0 y la otra es menos b entre a. Por ejemplo, x² − 5x = 0 da x = 0 y x = 5.

Ejemplo: x² − 5x + 6 = 0

Ejemplo con las cifras que trae la calculadora al abrirla: a = 1, b = −5 y c = 6. Primero el discriminante: D = (−5)² − 4 por 1 por 6, es decir, 25 − 24 = 1. Como es mayor que cero, hay dos soluciones reales distintas.

Ahora la fórmula general: x es igual a 5 más o menos la raíz de 1, entre 2. Las soluciones son (5 + 1) entre 2, que es 3, y (5 − 1) entre 2, que es 2. Comprueba con Cardano-Vieta: 3 + 2 es 5 y 3 por 2 es 6. El vértice está en x = 2,5, con altura −0,25. Para practicar, la calculadora de divisiones muestra el cociente y el resto paso a paso.

Preguntas frecuentes

¿Cómo se calcula el discriminante de una ecuación de segundo grado?

El discriminante es D = b² − 4ac. Si es mayor que cero hay dos soluciones reales distintas, si es cero hay una raíz doble y si es menor que cero las soluciones son complejas conjugadas.

¿Cuál es la fórmula general de las ecuaciones de segundo grado?

La fórmula general es x = (−b ± √(b² − 4ac)) / 2a. Se aplica a cualquier ecuación completa ax² + bx + c = 0 con a distinto de cero.

¿Cómo se resuelven las ecuaciones incompletas de segundo grado?

Si falta el término en x (ax² + c = 0), se despeja x² y se saca la raíz con los dos signos. Si falta el término independiente (ax² + bx = 0), se saca factor común x: una solución es 0 y la otra es −b/a.

¿Qué son las relaciones de Cardano-Vieta?

Las relaciones de Cardano-Vieta dicen que la suma de las dos raíces es −b/a y su producto es c/a. Sirven para comprobar en segundos si las soluciones que has calculado son correctas.

Importante: Esta calculadora resuelve ecuaciones con coeficientes reales. Si el discriminante es negativo, las soluciones son complejas conjugadas y se muestran con parte real e imaginaria. Si a es cero, la ecuación es de primer grado y la herramienta da su solución lineal.

Fuentes oficiales

El método es el estándar de álgebra: forma general ax² + bx + c = 0, discriminante D = b² − 4ac, fórmula general y vértice (−b/2a, c − b²/4a).
