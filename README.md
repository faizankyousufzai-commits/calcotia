# Calcotia — Free Online Calculators

**Official website: https://calcotia.online**

Calcotia is a collection of free online calculators for pay, benefits and leave,
in your own language and built on official rules. Every calculator is based on
the current official figures of its country, shows its formula, and includes a
worked example so you can check the result yourself.

## Calculators

- [Sykepenger kalkulator](https://calcotia.online/no/sykepenger-kalkulator/) — sick pay
- [Feriepenger kalkulator](https://calcotia.online/no/feriepenger-kalkulator/) — holiday pay
- [Foreldrepenger kalkulator](https://calcotia.online/no/foreldrepenger-kalkulator/) — parental benefit
