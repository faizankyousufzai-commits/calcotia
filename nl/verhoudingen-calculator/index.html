Wat is Verhoudingen Calculator?

De Verhoudingen Calculator vereenvoudigt verhoudingen en lost evenredigheden op. Vul een verhouding a : b in en een bekende waarde c, en de calculator berekent de onbekende x in de evenredigheid a : b = c : x.

Een verhouding vergelijkt twee getallen met elkaar. Een verhouding van 2 : 3 betekent dat er voor elke 2 delen van het ene, 3 delen van het andere zijn. Een verhouding van 4 : 6 is dezelfde verhouding, vereenvoudigd tot 2 : 3.

Evenredigheden gebruik je overal: in recepten, op kaarten, bij het mengen van verf en bij het omrekenen van valuta. Wie de verhouding kent, kan elke hoeveelheid omrekenen.

Andere termen die bij de Verhoudingen Calculator horen: kruisproduct, ratio en ggd.

Oefen met verschillende getallen om de formule echt te begrijpen: wie de formule kent, kan elke variant berekenen.

Wiskunde is een vaardigheid: wie regelmatig oefent, wordt sneller en maakt minder fouten.

Controleer je antwoord altijd met een schatting: klopt de grootte van je uitkomst met wat je verwacht?

De calculator rondt af op twee decimalen: voor school en klussen is dat nauwkeurig genoeg.

Wie de formule begrijpt, heeft geen calculator nodig: de calculator is een hulpmiddel, geen vervanging van inzicht.

Probeer het eerst zelf op papier en controleer daarna met de calculator: zo leer je het snelst.

Hoe werkt de Verhoudingen Calculator?

Vereenvoudigen doe je door beide getallen te delen door hun grootste gemene deler. De verhouding 4 : 6 wordt 2 : 3, omdat beide getallen deelbaar zijn door 2.

Een evenredigheid los je op met kruislings vermenigvuldigen: als a : b = c : x, dan is x gelijk aan b keer c gedeeld door a. Bij 2 : 3 = 4 : x is x gelijk aan 3 keer 4 gedeeld door 2, is 6.

De decimale waarde van een verhouding is a gedeeld door b. Bij 2 : 3 is dat 0,67.

Voorbeeld

De verhouding 2 : 3 is hetzelfde als 4 : 6. Los je de evenredigheid 2 : 3 = 4 : x op, dan is x gelijk aan 6.

Een recept met een verhouding van 2 delen bloem op 3 delen melk: heb je 4 koppen bloem, dan heb je 6 koppen melk nodig.

Voor wie is Verhoudingen Calculator nuttig?

Voor scholieren die verhoudingen oefenen, voor koks die recepten aanpassen, voor klussers die verf mengen, en voor iedereen die hoeveelheden wil omrekenen.

Wie een schaalmodel bouwt, gebruikt verhoudingen: een model van 1 : 50 is 50 keer kleiner dan het origineel.

Veelgestelde vragen

Hoe vereenvoudig ik een verhouding?

Deel beide getallen door hun grootste gemene deler. 4 : 6 wordt 2 : 3.

Hoe los ik a : b = c : x op?

x = b × c / a. Bij 2 : 3 = 4 : x is x = 3 × 4 / 2 = 6.

Wat is een evenredigheid?

Twee verhoudingen die gelijk zijn, zoals 2 : 3 = 4 : 6.

Hoe reken ik een recept om?

Gebruik de verhouding: heb je 2 keer zoveel bloem, dan heb je ook 2 keer zoveel melk nodig. Andere termen die hierbij horen: Evenredigheid, kruisproduct, ratio, ggd en vereenvoudigen.

Belangrijk: Een verhouding heeft geen eenheid. Zorg dat beide getallen in dezelfde eenheid zijn.
